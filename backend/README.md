# 見面排程後台（Google 全家桶版）

朋友在邀請卡按「直接傳給我」→ 資料進你的 Google 試算表 → 你收到 Email 通知 → 後台排日曆 → 一鍵寄「確定可以約」。全部免費、不用信用卡。

- `Code.gs`：後端程式（收資料、寄信、建日曆）
- `Admin.html`：後台畫面（排程日曆、所有回覆、誰還沒填）

## 設定步驟（約 10 分鐘，只做一次）

1. **建一個新的 Google 試算表**（sheets.new），取名「見面邀請回覆」。
2. 上方選單「**擴充功能 → Apps Script**」。
3. 左邊把預設的 `程式碼.gs` 內容全部刪掉，貼上本資料夾 `Code.gs` 的全部內容。
   - 找到第一個 `ADMIN_KEY`，把 `請改成你自己的密碼` 換成你自己的一串密碼（英數字，不要太簡單，也不要傳給別人）。
4. 左邊「檔案」旁按 **＋ → HTML**，檔名輸入 `Admin`（不用打 .html），把 `Admin.html` 全部內容貼進去。
5. 上方函式選單選 `setup`，按「**執行**」。會跳出授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→ 允許。這一步會建立「回覆」「名單」兩個分頁，並授權寄信和日曆。
6. 右上「**部署 → 新增部署作業**」，類型選「**網頁應用程式**」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「**網頁應用程式網址**」（`https://script.google.com/macros/s/.../exec`）。
7. 把網址貼到 `invite/index.html` 的 `CONFIG.sheetUrl`（或把網址傳給 Claude，請他貼上並部署）。
8. **後台網址**：網頁應用程式網址後面加 `?key=你的密碼`，例如
   `https://script.google.com/macros/s/.../exec?key=你的密碼`，加到瀏覽器書籤。
9. 在試算表的「名單」分頁（或後台「誰還沒填」）填上你要邀請的朋友暱稱，這樣才看得到誰還沒填。

> 之後改了 `Code.gs` 或 `Admin.html`，要「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」才會生效，網址不變。

## 使用
- **通知**：每有人送出，你的 Gmail 會收到信，內容包含對方填的資料、目前已填幾人、還沒填的人、後台連結。
- **排程日曆**：依日期列出「哪個時段誰可以」，點名字 → 選時間 → 「確認並建立日曆」。會建立在你的 Google 日曆，若該時段已有行程會先提醒。
- **寄確認信**：對方有留 Email 時，確認視窗可以勾選同時寄信（主旨、內容都能改）；沒留 Email 的會給你一段文字和 IG 連結，自己傳。
- **取消／改時間**：已確認的卡片上有按鈕，日曆活動會跟著更新或刪除。

## 隱私與安全
- 回覆只存在你的試算表；後台網址要帶你的密碼才打得開。
- 朋友送出的文字會先過濾（長度限制、避免試算表公式）。
- 信件是用你的 Gmail 寄出（每天約 100 封上限，一般夠用）。
- 蒐集 Email／IG 屬於個資，建議在邀請卡註明用途（只用來通知見面時間）。
