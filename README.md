# 我們怎麼看彼此

兩人線上或線下同玩的互動測驗：自評、互猜答案，揭曉相處落差與摩擦地圖，再抽對話卡深聊。

## 目前狀態

- `index.html`：遊戲本體。**目前依賴 claude.ai 內建的資料庫**，放在 GitHub Pages 上會顯示「連不上同步服務」，無法建立房間。
- `preview/result-preview.html`：結果頁案例預覽（虛構資料，可直接瀏覽）。
- `data/questions.v1.json`：原始題庫（五大人格白話版）。
- `data/questions.v2.json`：日常相處摩擦版題庫（5 軸、6 題摩擦情境、5 個形容詞）。

## 玩法

1. 選擇線上玩（不同時間地點）或線下玩（同一空間）。
2. 自我介紹 → 心理測驗 → 猜猜看 → 我們的關係。
3. 揭曉：默契分數、面向對照、摩擦地圖、形容詞三區、對話卡。

## 規劃

- 接上自己的後端（例如 Supabase），讓一般朋友免登入即可遊玩。
- 題庫改為讀取 `data/` 內的 JSON。

## 隱私

玩家的回答屬於個人資料，**不要上傳到本 repo**（`.gitignore` 已排除 CSV 與匯出檔）。
